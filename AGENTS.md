# Bobrs Battle Part 2

Поддерживай локальный запуск игры через `file://` без сети, сервера и сборки. Используй существующую структуру `index.html`, `code/` и `media/`. Сохраняй утверждённый дизайн, сценарии, игровые механики и оригинальные байты медиаресурсов. Меняй их только по прямому указанию пользователя. Для видео соблюдай настройки Git LFS.

## Автоматический выбор навыков

Перед изменениями определи, какие части игры затронуты. По таблице выбери все применимые навыки и прочитай их `SKILL.md` из рабочей копии, даже если текущая сессия Codex ещё не показывает их в каталоге. Применяй навыки совместно, если задача охватывает несколько областей.

| Задача | Навык |
| --- | --- |
| Кинематографические эффекты, магия, сцены Кроноса, духи и раскрытие карт | [`cinematic-vfx`](.agents/skills/cinematic-vfx/SKILL.md) |
| Трёхмерный бросок монеты, переворот карт, перспектива и пространственная анимация | [`3d-animation`](.agents/skills/3d-animation/SKILL.md) |
| Локальные ролики, анимированный WebP, переходы и управление воспроизведением | [`video-integration`](.agents/skills/video-integration/SKILL.md) |
| Игровые экраны, карточки, управление и состояния драфта | [`aaa-game-ui`](.agents/skills/aaa-game-ui/SKILL.md) вместе с [`frontend-design`](.agents/skills/frontend-design/SKILL.md) |
| Визуальная иерархия, типографика, композиция и адаптивная вёрстка | [`frontend-design`](.agents/skills/frontend-design/SKILL.md) |
| Готическое окружение, замок, ворота, тронный зал, пьедесталы и атмосферная анимация | [`gothic-environment-animation`](.agents/skills/gothic-environment-animation/SKILL.md) |
| Аудит игры, регрессии, производительность и локальная работа без сети | [`game-audit`](.agents/skills/game-audit/SKILL.md) |

Для кинематографической сцены в тронном зале применяй `gothic-environment-animation` и `cinematic-vfx`. Если в сцене используется ролик или анимированный WebP, добавляй `video-integration`. Если изменение броска монеты затрагивает интерфейс, совмещай `3d-animation`, `aaa-game-ui` и `frontend-design`.

## Проверка после изменений

После каждого визуального или технического изменения игры обязательно применяй `game-audit` перед завершением задачи. Проверяй затронутый сценарий и связанные переходы на реальных ресурсах через `file://` с отключённой сетью. Для визуальных изменений сравнивай снимки до и после на подходящих размерах экрана. После исправления повторяй затронутые проверки. В отчёте указывай, что проверено, какие ошибки найдены и какие сценарии или устройства остались непроверенными.
