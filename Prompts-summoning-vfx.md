# Промт для графики ритуала призыва

## Исходная графика пламени

**Формат.** один вертикальный RGBA-спрайт с настоящим альфа-каналом. Ориентир для мастера — 1024×1792. Центрируйте силуэт и оставьте мягкий запас вокруг кончиков языков. Камера фронтальная, кадр без перспективных искажений.

**Промт.** изолированный фотореалистичный сгусток магического огня для мрачного готического фэнтези. Пламя висит в воздухе. В нижней части компактная нить энергии цвета тёплой слоновой кости, вверх от неё выходят тонкие полупрозрачные языки. По краям видны складки огненных слоёв, изгибы, неоднородная плотность и тёмно-красный дым. Основная палитра состоит из янтарного, оранжевого и приглушённого тёмно-красного. Контраст сосредоточен в ядре, внешний край растворяется в прозрачность. Один компактный асимметричный силуэт, вытянутый примерно в пропорции 1:1,8. Стиль практических VFX, текстура читается в небольшом размере.

**Исключить.** шар, кольцо, сферическую ауру, неон, контурную обводку, белый фон, силуэты предметов, пол, отражение пола, надписи, рамки и отдельные удалённые искры.

**Для интеграции.** из одного изображения формируется атлас из двенадцати кадров. Меняются верхние языки пламени, нижнее ядро остаётся опорной точкой. Траектории, искры, шлейфы, свет и проявление карт синхронизируются игрой. Исходная иллюстрация зала используется отдельно без перерисовки.
