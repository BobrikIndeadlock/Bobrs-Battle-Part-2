# Bobrs Battle Part 2 · Ритуал десяти огней

Одобренные эффекты капитанов зафиксированы в `469d8d0`. Новый ритуал — `07d22fe` в ветке `gothic-visual-upgrade`.

## Реализация

- Десять огоньков стартуют из гримуара с интервалом 185 мс. Живые языки пламени и подвижное ядро рисуются из нового атласа с альфа-каналом. Размер, фаза и наклон варьируются для каждого огня. Шлейф запоминает предыдущие участки кривой и постепенно распадается на дымку и искры.
- Кривые Безье приводят огни к центрам реальных карточных ячеек 2×5. Позиции пересчитываются при изменении размеров. В двух рядах огни остаются в лёгком парении, а свет на камне и металле нарастает к вспышке.
- Вспышка локализована в зале. Направленные лучи, отражённый свет и расширяющаяся волна затухают отдельно. Рубашки проявляются после пика с небольшим сдвигом по времени, остаточный свет и искры рассеиваются. Карты становятся доступными после завершения последовательности.
- Новый слой использует один Canvas и локальные текстуры. Пауза освещения существующего зала и капитанов работает по своим прежним правилам. Сверены SHA-256 всех 66 ранее одобренных медиафайлов.
- В уменьшенном движении работает короткое проявление без полёта и вспышки. При недоступной текстуре раздача переходит в обычное состояние выбора.

## game-audit

- В непрерывной записи реальной игры проверены старт из гримуара, двадцать проходов текстуры на кадре построения (два слоя у каждого из десяти огней), отсутствие рубашек до вспышки, расширяющаяся волна и десять доступных карт после проявления.
- Пройдены уменьшенное движение, недоступный атлас, смена ориентации и перезапуск посреди полёта. При повторном запуске существует ровно один холст. Отработал также портретный размер 390×844 с касанием.
- Полный регрессионный прогон охватил вступление, Зал легенд, первый драфт 5+5, обе сцены Кроноса, финальный ролик с перемоткой, 18 ходов Deadlock, отмену, загрузку локального портрета и экспорт PNG. Часть игровых ожиданий в тесте была сокращена, длительность нового ритуала проверена отдельно в реальном времени.
- Chromium запускался через `file://` без сети. Внешних запросов в аудитах не было. Синтаксис JavaScript и Git LFS проверены.
- Видеофайл H.264 1280×720 записан с живой сцены непрерывным планом и полностью декодирован. В контрольном видео вспышка выделяется в центре, остальная сцена остаётся читаемой. Это визуальная проверка, без оценки на физических дисплеях.
- Промт для создания исходной графики живого пламени находится в [Prompts-summoning-vfx.md](Prompts-summoning-vfx.md).

## Производительность

Два последовательных прогона призыва для каждой версии и каждого профиля. Headless Chromium, локальный запуск, без записи видео во время замеров. p95 измеряет интервал `requestAnimationFrame`. Время JavaScript и пересчёта стилей приводится за весь призыв.

| Профиль | p95 до → после | JavaScript до → после | Пересчёт стилей до → после |
| --- | --- | --- | --- |
| 1440×810, DPR 1 | 50,1–83,3 → 16,7–16,8 мс | 37–44 → 94–104 мс | 189–238 → 16–27 мс |
| 812×375, DPR 2, CPU 4× медленнее | 50,0 → 16,7–16,8 мс | 101–170 → 392–454 мс | 1215–1245 → 68–110 мс |

Длительность нового призыва до разблокировки карт — около 6,8 с против 5,6–5,7 с в контрольной версии. В мобильных выборках видны один и два интервала длиннее 50,5 мс соответственно. Разрешение временного холста — 960×540 или 640×360. Он удаляется по завершении. Измерения GPU, Safari и физические мобильные устройства в этот прогон не входили.

В рабочем каталоге аудита использовались `node record-final.cjs`, `node edge.cjs`, `QA_FAST=1 QA_BROWSER=chromium node qa.cjs` и `node bench.cjs`. Сырые замеры в [summoning-performance.json](summoning-performance.json).
