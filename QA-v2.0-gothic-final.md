## Игровые сценарии

Проверка проводилась в Chromium из распакованного ZIP через `file://` с отключённой сетью.

| Проверка | Результат |
| --- | --- |
| Десктоп 1440×900 | Пройдены ворота, тронный зал, зал легенд, призыв, первый драфт, обе сцены Хроноса, полный финальный ролик, монета, Deadlock и экспорт PNG |
| Мобильный профиль 390×844 | Пройден тот же цикл с тач-вводом, проверен ручной запуск ролика при блокировке автовоспроизведения и пауза при сворачивании |
| Гримуар | Все десять сфер, поворот окна без перезапуска анимаций, быстрые нажатия, сброс, режим уменьшенного движения и десять доступных карт |
| Оба драфта | Составы 5+5, возврат и печать карты, оба исхода монеты, 18 ходов Deadlock, 6 банов и 12 пиков, отмена хода и PNG 1600×900 |
| Жизненный цикл эффектов | Сворачивание и возврат через событие видимости, прерывание переходов, повторный запуск и остановка скрытой отрисовки |
| Автономность | В полных прогонах зафиксировано 0 внешних запросов и 0 необработанных ошибок JavaScript |

В десктопном прогоне сохранены штатные таймеры и финальный ролик проигран целиком. В мобильном прогоне ускорены вспомогательные ожидания и выполнена проверка воспроизведения с перемоткой. Мобильный профиль воспроизводит размер окна и тач-ввод в Chromium. Проверки на физическом iPhone и в HTML Web Preview остаются за пределами этого стенда.

## Плавность и повторные запуски

Повторный замер из нового ZIP в профиле 390×844 дал 59,1 обновления положения в секунду в среднем по десяти сферам. Интервал p95 на участке вылетов составил 16,7 мс.

Игровые JavaScript и CSS побайтно совпадают с одобренным исправлением плавности. Численные замеры предыдущей сборки применимы к этим же игровым файлам. [Замеры по каждой сфере](QA-summoning-smoothness.md) · [Замеры памяти и эффектов восьмого этапа](QA-gothic-final.md)

Полные прогоны выполнены скриптом `qa.cjs` с `QA_BROWSER=chromium` и `QA_GAME=extracted-final`, с `QA_COIN_BIT=0` для десктопа, и с `QA_PROFILE=phone QA_COIN_BIT=1 QA_FAST=1 QA_BLOCK_AUTOPLAY=1 QA_FILM_PAUSE=1` для мобильного профиля. Проверки прерываний выполнены скриптами `ritual-check.cjs` и `lifecycle.cjs`.
