# Bobrs-Battle-Part-2
Bobrs Battle Part 2 — Full Edition

## Локальный запуск

Получите рабочую копию через Git с установленным [Git LFS](https://git-lfs.com/).
В папке репозитория выполните `git lfs pull`, чтобы скачать финальный ролик,
затем откройте `index.html` в браузере. После загрузки файлов игру можно запускать
без интернета, сервера и сборки.

- `code/js/` и `code/css/` содержат код и стили игры, включая анимации.
- `media/images/` и `media/video/` содержат изображения и ролик из исходной версии.
- `media/deadlock/portraits.js` содержит исходные миниатюры из [Deadlock Wiki](https://deadlock.wiki/Heroes)
  в формате data URL для локальных анимаций героев и экспорта составов в PNG.
