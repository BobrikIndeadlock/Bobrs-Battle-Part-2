# Публикация второго этапа

Workflow публикует только каталог, собранный командой:

```sh
python3 online-deadlock/build.py _site
node --test online-deadlock/rules.test.mjs
```

Сборщик берёт оригинальную разметку, стили, эффекты, звуки и порядок 18 ходов из игры. Дополнения к интерфейсу применяются только к копии контроллера в артефакте Pages.

Локальная игра передаёт в HTTPS-вкладку два списка идентификаторов в фрагменте URL. После проверки модуль удаляет данные из адреса и использует только утверждённые имена и портреты. Ссылка для гостя содержит случайный идентификатор комнаты. Она не содержит составы. Первый вошедший гость занимает место Артемона и сохраняет ключ переподключения в браузере.

Ведущий хранит составы и ревизию драфта в памяти и проверяет каждое действие, включая очередь, уже использованных героев и текущую ревизию. По восстановленному каналу WebRTC он отправляет полный снимок. Монетка и первый экран драфта запускаются ведущим. Последний экран сохраняет привычный экспорт PNG. Отмена и загрузка собственных портретов доступны в локальном режиме.

Клиент PeerJS 1.5.5 включён вместе с лицензией MIT. Используется бесплатная публичная сигнализация PeerJS. Хранилище на сервере отсутствует. Если вкладка ведущего закрыта, вернуть её состояние нельзя.
