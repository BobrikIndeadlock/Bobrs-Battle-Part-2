# Веб-версия сезона «Изумруд и гром»

Соберите сайт из ветки сезона. Если для сезона добавлен ролик, сначала загрузите его через Git LFS.

```sh
python3 online-deadlock/build.py _site
node --test online-deadlock/rules.test.mjs
```

Для игры с разных устройств разместите каталог `_site` на одном HTTPS-адресе. Для двух браузеров на одном компьютере подойдёт `python3 -m http.server 8792 --directory _site`. Локальная игра по `file://` запускается через исходный `index.html`.

После входа в замок ведущий (Павел) создаёт комнату до призыва колоды и отправляет приглашение Мишане. По окончании первого драфта ведущий открывает Deadlock в той же комнате. При игре локально на веб-странице можно создать комнату со второго этапа и передать в неё оба состава.

Сетевые команды проверяет вкладка ведущего. Гость восстанавливается по той же ссылке в прежнем профиле браузера, пока ведущий в комнате. Идентификаторы содержат название сезона, поэтому ссылки старого сезона ведут в прежнюю игру.

PeerJS 1.5.5 поставляется вместе с лицензией MIT. Ведущий и гость задают явные локальные идентификаторы. Игра открывает WebSocket к публичному PeerJS сразу, а игровые данные передаются через WebRTC. При обрыве сигнализации происходят до двух автоматических повторов. Явный отказ останавливает попытки.

В Deadlock попадают два состава из подтверждённого снимка первого драфта. При повторном входе гость получает те же составы, результат монеты и текущие пики и баны.
